# 方向宣言

- 目的：鳥取の事業者が、サイトの更新・移行・運用の相談先として、対応範囲と実績を確認できる。
- 本人指定：養蜂の印象を前面に出さず、シックで信頼性のあるサイトへ。本人写真は残してよい。
- レジスター：主＝精密、副＝静謐。サーフェス＝Web。
- 地 #F5F5F2、面 #FFFFFF、文字 #252B2B、暗い面 #202728、補助文字 #606968、境界 #D7DCDA、アクセント #335C53。単発料金の補助色 #756449 / #F6F3ED、月額 #EDF2F0。
- タイポ：和文 Zen Kaku Gothic New 400/500/700。既存の自己配信を維持し、本文の読みやすさと角の整った印象を採用。英数字 Outfit 500/600、料金はtabular-nums。PC見出し50px・スマホ30px、本文17px/1.9。
- 余白：8px基準、PCセクション80px、スマホ56px、最大幅1120px。角丸2px。派手な陰影なし。
- モーション：色変化160msのみ。バウンス・飛行なし。reduced-motionで動きを抑える。
- 見せ場：冒頭に「現状確認・構成の見直し・公開後の管理」の3行を静かな案内として置く。診断済み・監視中に見える架空の画面を作らない。
- 本人写真は担当者紹介に1点。実績写真と11デモは保持。養蜂は経歴として正直に残す。
- 禁止：蜂の装飾、黄色いマーカー、丸い認定風スタンプ、AI生成素材、架空資格や安全保証。
- 構成は困りごと→対策の進め方→実例→料金→担当者→管理の約束を継承。セキュリティニュースは日付・一次出典付きの情報欄に整理。
- 価格・4点10万円・月額との区別・SNS3/5/最大10媒体は変更しない。SNS専用LP・農業サイトは今回の対象外。

# 内部検討

既読の両脳資料とチェック表を再利用。顧客の不安が主役、実績は制作・運用の実物に限定、料金を下げず無料相談へ接続。見た目だけで専門資格や緊急対応力を印象づけない。安全保証を足さず、管理範囲・担当・バックアップ・引渡しを具体化する。

暗い画面を全ページに使う案と、白主体に冒頭だけチャコールを使う案を比較。長文・料金の可読性を優先し後者を採用。本人のAI画像を使わない指定を優先し、生成モックは作らず実コードをChromeで検品する。

## 2026-10-23 追加2：無料診断の入口

- 目的：自社サイトの管理を見直したい事業者へ、無料診断の入口と移行相談への道筋を示す。
- 方向：白とチャコール、深い緑の既存デザインを継承。冒頭は診断名とURL欄を優先し、AI画像・架空の診断結果・認定風の表示を使わない。
- 本人指定：別担当の受け渡しファイルが届くまでは「準備中」。入力欄とボタンは無効で、送信・保存・診断を行わない。時事の事件名と不安をあおる導入は外す。
- 導線：診断の表示枠の下→「安藤青果に引っ越しを頼む」→移行3万円〜の料金行。既存の制作4点10万円・SNS3/5/最大10媒体・実績7件・デモ11件は維持。
- 内部点検：無料入口から有料移行の範囲・価格に進める。専門診断や安全保証と誤解させず、準備段階を明記する。名前・講義内容の外部掲出なし。
- 完了条件：ビルド、変更箇所のlint、PC/375px/320pxのChrome実画面と料金リンク、公開差分の限定、総合90点以上・重大指摘ゼロ。その後に本番反映・本番確認。
- 公開はLPのみ。Cloudflare移行の基盤変更は別案件として保持し、メールなどの確認前に本番へ混ぜない。

## 2026-10-23 追加4：点検から移行代行へ
- 無料の入口は「サイト点検キット」。WordPressだけでなく公開HTML・HTTPS・DNSの手がかりを確認する。
