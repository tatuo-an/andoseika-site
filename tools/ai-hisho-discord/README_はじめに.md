# これは何か

Discordにメッセージを送ると、あなたのパソコンで動いているClaude Code（AI）が読んで、Discordに返事を書いてくれる仕組み一式です。

パソコンを開かなくても、スマホのDiscordアプリから「今日のニュース調べて」「これ下書き作って」のようにお願いできるようになります。

# あなたがやることは3つだけ

1. このフォルダ（zipを解凍したもの）を、好きな場所に置く（デスクトップでもドキュメントでもOK）
2. **このフォルダの中で** Claude Codeを開く
3. Claude Codeに「`SETUP_FOR_AI.md` を読んで、Discord常駐を設置して」と言う

あとはAIが1手順ずつ、画面を確認しながら案内してくれます。あなたはDiscordの画面をクリックしたり、コピーしたものを貼り付けたりするだけで大丈夫です。コードを書く必要は一切ありません。

# 所要時間の目安

30〜40分ほどです（Discordの画面を行ったり来たりする作業が中心です）。

# 必要なもの

- Discordのアカウント（無料。持っていなければAIが作り方から案内します）
- Claude Codeが動くパソコン（Windows／Mac どちらでも可）
- パソコンがネットにつながっていること

**このパソコンの電源が入っていて、ネットにつながっているときだけAI秘書は反応します。** パソコンをシャットダウンしている間は反応しません（スリープなら大丈夫な場合が多いですが、環境によります）。

# パソコンを常時つけたくない人へ

「四六時中パソコンをつけっぱなしにするのは気が引ける」という方は、パソコンの代わりに小さなクラウドサーバーを借りて、そこでAI秘書を動かす方法もあります。月数百円〜の利用料はかかりますが、パソコンの電源に左右されなくなります。詳しくは同梱の `RAILWAY.md` をご覧ください（この方法はまだ実機での動作確認をしていません。まずはパソコンでの常駐から試すことをおすすめします）。

# 注意していただきたいこと

- **Botのトークン（合鍵にあたる文字列）は、絶対に人に見せたり、SNSやスクリーンショットに写したりしないでください。** 流出すると他人があなたのBotになりすませてしまいます。
- このzip自体は、コミュニティ内で配られている配布物です。ご自身の設置が終わったら、zipごと他の人（コミュニティ外）へ再配布しないでください。
- AI秘書は「ファイルの削除・上書き」「SNSへの投稿・公開」「外部への送信」「支払いなどお金が動く操作」を自分の判断では実行しません。必要なときは「パソコンの前で承認をください」と返してきます。安心してご利用ください。

# 許可の設定について（「毎回聞かれる」を無くすコツ）

設置の途中で、Claude Codeから「これをやっていいですか？」という確認画面（許可ダイアログ）が何度か出ます。だいたい次の2つの選択肢があります。

- **「1回だけ許可」**: 今回だけOKにする。次に同じことをするときは、また聞かれます。
- **「常に許可」（「今後は聞かない」等の表記のこともあります）**: 一度OKにすると、次からは聞かれなくなります。

**「1回だけ」を選び続けると、いつまで経っても毎回聞かれます。** 「すごい頻度で聞かれる」という声の多くは、これが原因です。中身を確認して問題なければ、基本は「常に許可」を選んでください。設置1日目に出てくる確認は、まとめて「常に許可」で答えてしまうのがいちばん楽です。

さらに、設置の終盤でAIが「よく使う操作」をあらかじめ設定ファイル（`.claude/settings.json`）へ登録してくれます。これをやっておくと、AI秘書がスマホからの依頼に応えるとき（調べ物・下書き作成など）、いちいち確認せずに動けるようになります。**削除・公開・外部送信・支払いなど、危険な操作はこの登録の対象外のままです**（そこは今までどおり「承認をください」と聞いてきます。安全のため、あえてそうしてあります）。登録する内容は、設置前にAIから一言説明がありますので、目を通してからOKしてください。

# うまくいかないとき

`SETUP_FOR_AI.md` の最後に「切り分け表」があります。Claude Codeに「常駐が動かない」と伝えれば、AIがそこを読んで原因を調べてくれます。

# 中身のファイル

- `bridge.mjs` … 本体プログラム（AIが動かします。中身を書き換える必要はありません）
- `setup-helper.mjs` … 設置作業を自動化する補助プログラム（トークン保存・設定ファイル作成・自動起動の登録をAIがこれ1つでまとめて行います。人間が直接触る必要はありません）
- `package.json` … 必要な部品（discord.js）の一覧
- `config.json.example` … 設定ファイルの見本（AIが実際の値を入れて `~/.config/ai-hisho/config.json` として保存します）
- `SETUP_FOR_AI.md` … **AI向け**の設置手順書（人間が読む必要はありません。AIに読ませてください）
- `RAILWAY.md` … パソコンを常時つけたくない人向けの別ルート
- `templates/` … 自動起動の設定ファイルの雛形（`setup-helper.mjs`が使います）

# 秘書の名前について

「AI秘書」という表記は仮の呼び方です。設置の一番最初に、AIから「お好きな名前を付けてください」と聞かれます。決めた名前で、以後ずっとその名前として返事をしてくれるようになります（このキット自体に固定された名前はありません）。
